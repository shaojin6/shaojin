完整的联动流程
1. Agent → MCP 服务绑定
Agent（kubernetes-mcp-server Agent）通过 MCPServerID 绑定到 MCP 服务
验证 MCP 服务存在且已启用
2. MCP 服务 → K8s 配置
MCP 服务配置中的 Headers 包含 Authorization token
该 token 对应"生产环境集群2"的 K8s 认证信息
工具调用时，token 会通过 HTTP Headers 传递给 kubernetes-mcp-server
3. LLM 配置
始终使用默认 LLM（bailian）
验证 API Key 是否配置
4. 工具列表加载
聊天前自动刷新工具列表
从缓存（Redis/MySQL）或远程 MCP 服务加载
验证工具列表是否为空
5. 智能问答流程
   用户消息 → LLM 分析 → 决定调用工具 → MCP 协议调用工具    → kubernetes-mcp-server 使用 K8s token 连接集群    → 返回结果 → LLM 分析结果 → 返回最终答案
