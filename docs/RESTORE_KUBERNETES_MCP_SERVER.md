# 恢复 Kubernetes MCP Server 配置

## 快速恢复

### 在 Web UI 中重新添加

1. 打开 Web UI：`http://localhost:9090`
2. 进入"配置管理" -> "MCP 配置"
3. 点击"+添加 MCP 服务"
4. 填写以下配置：

```
服务终点 URL: http://11.0.1.110:30080/mcp
名称: kubernetes-mcp-server
服务器标识符: kubernetes-mcp-server
协议类型: HTTP/REST API
超时时间: 30
SSE 读取超时时间: 300
前端超时时间: 0（使用全局配置）
工具端点: （留空，会自动尝试多个路径）
```

5. 点击"保存"

## 配置说明

- **服务终点 URL**: `http://11.0.1.110:30080/mcp`
- **名称**: `kubernetes-mcp-server`
- **服务器标识符**: `kubernetes-mcp-server`（必须与名称一致）
- **超时时间**: 30 秒
- **SSE 读取超时时间**: 300 秒
- **前端超时时间**: 0（使用全局配置，默认 5 分钟）

## 验证

添加后，应该能看到：
- 工具数量：21 个工具
- 状态：已启用

## 原因分析

从文件备份和 Agent 配置可以看出，之前确实有 `kubernetes-mcp-server`，但在某个时候丢失了。

可能的原因：
1. 数据库迁移时未正确迁移
2. 保存其他服务时意外覆盖
3. 服务重启时数据加载问题

## 预防措施

1. **定期备份数据库**
2. **检查保存逻辑**：确保保存一个服务时不会影响其他服务
3. **添加数据验证**：在保存前验证数据完整性
