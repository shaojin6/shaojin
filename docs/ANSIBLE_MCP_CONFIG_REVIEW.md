# Ansible MCP Server 配置审查

## 当前配置分析

### ✅ 正确的配置项

1. **服务名称**: `ansible-mcp-server` ✅
2. **服务器标识符**: `ansible-mcp-server` ✅
3. **协议类型**: `HTTP/REST API` ✅
4. **SSE 读取超时**: `600` 秒 ✅（已增加到 10 分钟）

### ❌ 需要修正的配置项

#### 1. **服务终点 URL（关键问题）**

**当前配置**：
```
http://11.0.1.110:8080/sse
```

**问题**：
- ❌ 使用了容器内部端口 `8080`
- ❌ 外部无法直接访问容器端口
- ❌ 应该使用 NodePort `30091`

**正确配置**：
```
http://11.0.1.110:30091/sse
```

**原因**：
- 您的 K8s Service 配置了 NodePort 30091 → 容器端口 8080
- 外部访问必须通过 NodePort 30091
- 容器端口 8080 只在 K8s 集群内部可访问

#### 2. **超时时间**

**当前配置**：
```
超时时间: 300 秒（5 分钟）
```

**建议**：
```
超时时间: 60 秒
```

**原因**：
- 300 秒对于 HTTP 请求来说太长了
- 60 秒足够处理大多数请求
- SSE 读取超时已经设置为 600 秒，可以处理长时间连接

#### 3. **请求头（可能有问题）**

**当前配置**：
```
Authorization: 1
```

**问题**：
- ❌ `Authorization: 1` 看起来不对
- ❌ 通常应该是 `Authorization: Bearer <token>` 格式
- ❌ 或者如果不需要认证，应该删除

**建议**：
- 如果 ansible-mcp-server **不需要认证**，删除这个请求头
- 如果需要认证，应该是 `Authorization: Bearer <your-token>`

1. 点击 `Authorization: 1` 旁边的"删除"按钮

2. 点击"+添加请求头"
3. 添加：
   - Key: `Authorization`
   - Value: `Bearer <your-actual-token>`

1. 点击"保存"按钮
2. 在 MCP 配置列表中，点击"测试"按钮

## 常见问题

### Q1: 为什么必须使用 30091 端口？

**A**: 因为您的 K8s Service 配置了 NodePort 30091。外部访问必须通过 NodePort，容器端口 8080 只在集群内部可访问。

### Q2: 超时时间 300 秒可以吗？

**A**: 可以，但 60 秒更合理。SSE 读取超时 600 秒已经足够处理长时间连接。

### Q3: Authorization 请求头是必需的吗？

**A**: 取决于 ansible-mcp-server 的配置。如果不需要认证，应该删除。如果需要，格式应该是 `Bearer <token>`。
