# 日志查看功能使用指南

## 功能概述

系统日志查看功能允许你在 Web 界面中实时查看服务日志，方便调试和监控系统运行状态。

## 访问方式

1. **打开 Web 界面**
   - 访问 `http://localhost:9090`
   - 登录后，点击左侧菜单的 **"系统日志"**

2. **日志查看页面功能**
   - 显示最新的系统日志
   - 支持过滤搜索
   - 支持自动刷新
   - 可调整显示行数

## 功能说明

### 1. 查看日志
- 默认显示最后 100 行日志
- 日志以深色背景显示，便于阅读
- 自动滚动到底部，显示最新日志

### 2. 过滤日志
- 在搜索框中输入关键词（如：`LLM`、`Orchestrator`、`ERROR`）
- 按回车或点击刷新按钮应用过滤
- 支持大小写不敏感搜索

### 3. 调整显示行数
- 下拉菜单选择：
  - 最后 50 行
  - 最后 100 行（默认）
  - 最后 200 行
  - 最后 500 行

### 4. 自动刷新
- 点击"自动刷新"按钮启用
- 每 3 秒自动刷新日志
- 再次点击可停止自动刷新

### 5. 手动刷新
- 点击"刷新"按钮立即更新日志
- 或使用快捷键刷新页面

## API 接口

### GET /api/logs

获取系统日志。

**查询参数：**
- `lines` (可选): 返回的行数，默认 100，最大 1000
- `filter` (可选): 过滤关键词，大小写不敏感

**示例：**
```bash
# 获取最后 50 行日志
curl http://localhost:9090/api/logs?lines=50

# 过滤包含 "LLM" 的日志
curl http://localhost:9090/api/logs?filter=LLM

# 组合使用
curl http://localhost:9090/api/logs?lines=200&filter=ERROR
```

**响应格式：**
```json
{
  "lines": [
    "2025/12/03 10:05:17 router.go:112: MySQL cache connected.",
    "2025/12/03 10:05:17 router.go:139: MONGODB_HOST loaded from env: 11.0.1.110"
  ],
  "total": 4087,
  "filtered": 4087,
  "showing": 10
}
```

## 常见使用场景

### 1. 调试 LLM 调用
- 过滤关键词：`LLM` 或 `DashScope`
- 查看 LLM API 调用详情
- 检查模型名称和响应时间

### 2. 调试工具调用
- 过滤关键词：`Tool` 或 `Orchestrator`
- 查看工具调用过程
- 检查工具返回结果

### 3. 查看错误信息
- 过滤关键词：`ERROR` 或 `failed`
- 快速定位错误
- 查看错误详情

### 4. 监控系统状态
- 查看启动日志
- 检查连接状态（MongoDB、MySQL、Redis）
- 监控服务运行情况

## 注意事项

1. **日志文件大小**
   - 日志文件 `service.log` 会持续增长
   - 建议定期清理或配置日志轮转

2. **性能考虑**
   - 显示大量日志可能影响性能
   - 建议使用过滤功能缩小范围
   - 最多返回 1000 行日志

3. **实时性**
   - 手动刷新：立即获取最新日志
   - 自动刷新：每 3 秒更新一次
   - 日志文件写入可能有延迟

4. **安全性**
   - 日志可能包含敏感信息（API Key、Token 等）
   - 请确保只有授权用户能访问日志
   - 生产环境建议添加访问控制

## 日志格式

日志格式：`时间 文件名:行号: 日志内容`

示例：
```
2025/12/03 10:05:17 router.go:112: MySQL cache connected.
2025/12/03 10:05:17 orchestrator.go:109: [Orchestrator] ========== LLM Call #1 ==========
```

## 故障排查

### 问题1：看不到日志
- 检查服务是否正常运行
- 检查 `service.log` 文件是否存在
- 查看浏览器控制台是否有错误

### 问题2：日志不更新
- 点击"刷新"按钮
- 检查自动刷新是否启用
- 确认服务正在写入日志

### 问题3：过滤不工作
- 确认关键词拼写正确
- 尝试使用更通用的关键词
- 检查是否有匹配的日志
